Backup & Restore

Download a full snapshot of all config files and images, or restore from a previous backup.

⬇️ Download Backup

Creates a .zip containing autoreply.json, messages.json, settings.json, schedules.json, customers.json and all payment images. Your live config is not affected.

⬆️ Restore from Backup

Upload a .zip previously created by this dashboard. Each config file is validated before writing — if any file fails validation the entire restore is aborted. Runtime state files (agentmode.json, ooo.json) are never overwritten.
